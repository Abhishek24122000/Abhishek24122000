##  Featured Project: Cold Mail Generator

🔗 **Live Demo:** [Cold Email Generator](https://coldemailgenerator-tool.streamlit.app)

> **AI-Powered Personalized Outreach Tool**  
> Built with Streamlit, LangChain, and LLaMA 70B via Groq API

 **Key Features:**
- Scrapes job listings from career pages
- Extracts resume context from PDF
- Injects portfolio/project links
- Generates multilingual, clean, personalized cold emails
- Built-in tone & type selector (job, collab, follow-up, mentorship)

 **Tech Stack:**  
`Streamlit` · `LangChain` · `PyMuPDF` · `Groq API` · `LLaMA 70B` · `Prompt Engineering`
