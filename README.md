## 🚀 Featured Project: Cold Mail Generator

**Cold Mail Generator — AI-Powered Personalized Outreach Tool**  
Transforms careers pages into personalized, resume-aware, multilingual cold emails using LLMs.

🔗 [Live Demo](https://coldemailgenerator-tool.streamlit.app)

### Key Highlights
- Scrapes job descriptions from any URL
- Upload your resume (PDF)
- Inject portfolio or project links
- Choose purpose (job, internship, collab, etc.)
- Outputs clean, tailored cold emails (multiple languages)

### Built With:
- **Frontend:** Streamlit  
- **Scraping:** LangChain WebBaseLoader  
- **Resume Parsing:** PyMuPDF  
- **LLM Engine:** Meta LLaMA 70B via Groq API  
- **Backend Logic:** Python, Prompt Engineering
